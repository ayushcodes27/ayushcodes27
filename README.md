## 🛠️ Things I've Built

**[SAGE Engine](https://github.com/ayushcodes27/sage-engine)** — High-throughput reverse proxy mitigating automated bot traffic via ML behavioral analysis. Sub-0.4ms gate latency via Java 21 Project Loom virtual threads, Redis Lua token buckets, and decoupled FastAPI telemetry inference.  
`Java 21` `Kafka` `Redis` `FastAPI` `Docker`

**[LedgerFlow](https://github.com/ayushcodes27/ledger-flow)** — Distributed financial ledger engine guaranteeing zero double-spending. Features two-tier locking (Redisson + PostgreSQL `@Version`), Transactional Outbox pattern to eliminate dual-writes, and Saga rollback orchestrations.  
`Java 21` `Spring Boot` `Kafka` `PostgreSQL` `Redis`

**[DocAgent](https://github.com/ayushcodes27/doc-agent)** — Autonomous invoice processing pipeline with LangGraph cyclic state machines. Integrates dual-reader multimodal vision extraction, 9 deterministic rule assertion guards, and tamper-evident SHA-256 audit trails.  
`Python` `LangGraph` `FastAPI` `Docker`

**[Aviate](https://github.com/ayushcodes27/aviate)** — Vectorized OLAP data pipeline processing 6.4M+ flight logs for sub-250ms analytical queries. Orchestrated with containerized Airflow DAGs, dbt Core dimensional star-schemas, and DuckDB.  
`DuckDB` `dbt Core` `Airflow` `Next.js` `Supabase`

**[ClinicFlow](https://github.com/ayushcodes27/clinic-flow)** — Real-time clinic queue orchestration suite. Delivers sub-50ms live queue synchronization to room displays via STOMP WebSockets, role-based JWT auth, and conflict-free appointment booking.  
`Spring Boot` `WebSocket` `React` `PostgreSQL`
